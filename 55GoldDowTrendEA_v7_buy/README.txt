GoldDowTrendEA_v7_buy (Gold / H4 / ダウ理論転換ブレイク / 買い専用)

導入手順:
1. install.ps1 を使うか、このセットの MQL4 とリポジトリ直下の templates を MT4 の「ファイル→データフォルダを開く」へ上書きコピー
2. MT4 を再起動
3. チャートにEAをドラッグし、MQL4\Presets\*.set を読み込む
4. ツール→オプション→エキスパートアドバイザ で「WebRequestを許可するURL」に
   https://nfs.faireconomy.media を追加 (ニュースフィルター使用時)
5. テンプレートはチャート右クリック→テンプレート→読み込み
